# cn-home-pages

本仓库用于归档和发布多个独立的 HTML 页面。这些页面以静态 HTML 文件形式存放，可通过 GitHub Pages 直接访问，便于浏览和分享。

## 项目简介

cn-home-pages 是一个 HTML 页面归档仓库，旨在以简洁、可维护的方式保存和展示一系列独立网页。每个页面都是自包含的 HTML 文件，不依赖后端服务，适合作为个人项目、资料展示或轻量级页面集合。

## 目录说明

```
├── index.html           # 首页（可选，用于导航）
├── pages/               # 存放所有 HTML 页面的目录
│   ├── example.html     # 示例页面
│   └── ...
├── assets/              # 公共资源（CSS、JS、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md            # 本文件
```

- `pages/`：所有独立 HTML 页面均放置在此目录下，每个文件对应一个页面。
- `assets/`：页面共享的静态资源，如样式表、脚本和图片。
- `index.html`：可选的入口页面，用于提供页面列表或导航。

## 页面归档说明

- 每个页面均为独立的 HTML 文件，可直接在浏览器中打开。
- 页面之间无耦合，可单独修改、添加或删除。
- 资源引用建议使用相对路径，以确保在本地和 GitHub Pages 上均能正常加载。
- 如需添加新页面，请在 `pages/` 目录下新建 HTML 文件，并可选在 `index.html` 中添加链接。
